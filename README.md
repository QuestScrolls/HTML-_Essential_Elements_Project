# Thomas J. Watson Fan Page — HTML Essentials Project

A simple static web page dedicated to **Thomas J. Watson Sr.** , built to demonstrate fundamental HTML elements. The page includes a short biography, an image, a table showing IBM's growth, and an insights submission form with various input fields. This project was created as part of the **HTML Essentials** module by IBM on Coursera.

## 📚 Project Overview
This project consolidates core HTML tags into a real-world example: a memorial/fan page for a historical figure. It focuses purely on HTML structure, without any CSS or JavaScript, illustrating how semantic markup alone can create a functional, accessible webpage.

## 🔍 HTML Elements Showcased
- **Headings**: `<h1>`, `<h2>`
- **Image**: `<img>` with `src`, `width`, `height` (external URL)
- **Paragraph**: `<p>`
- **Unordered List**: `<ul>`, `<li>`
- **Table**: `<table>`, `<tr>`, `<th>`, `<td>`
- **Hyperlink**: `<a>` (external link to ibm.com)
- **Form**:
  - `<fieldset>` and `<legend>`
  - `<label>` with `for` attribute
  - `<input>` of type `text` and `email` (with `required` and `placeholder`)
  - `<textarea>`
  - `<button type="submit">`
